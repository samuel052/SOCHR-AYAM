# ביקורת בינארית מלאה של K.com

מטרת התיקייה היא לתעד כיסוי רציף של כל 52,098 הבתים בקובץ המקור, ולא רק את שגרות המשחק
שכבר זוהו. כתובות בדוחות הן כתובות זיכרון של קובץ COM הטעון ב־`0x100`; סוף הקובץ הוא `0xCC82`
בלעדי.

הביקורת מחולקת לשלושה טווחים רציפים שאינם חופפים. הסיכום המאוחד והכרעות ההתאמה נמצאים
ב־`00-master.md`; ביקורת עקביות המסמכים נמצאת ב־`04-document-consistency.md`:

- `01-low`:‏ `0x0100–0x44FF` — ספריות זמן־ריצה, DOS, תצוגה, קלט ו־Real.
- `02-mid`:‏ `0x4500–0x87FF` — עזרי מצב, מחירים, אירועי בוקר, מסחר ובנק.
- `03-high`:‏ `0x8800–0xCC81` — שודדים, הפלגה, תפריט, אתחול וסיום.

כל דוח חייב להבחין בין קוד בר־השגה, קוד ספרייה שאינו נקרא, נתונים, מחרוזות inline, טבלאות
ומשאבים. קובצי ה־CSV משמשים לבדיקת כיסוי מכונתית ולמציאת חורים או חפיפות.
