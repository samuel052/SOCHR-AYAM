# פרק 7 — שודדי הים: קרב, בריחה וכופר (מפוענח במלואו)

> המפרט הסופי המחייב: [10 - מפרט מנוע מאומת סופית.md](10%20-%20מפרט%20מנוע%20מאומת%20סופית.md).

> מוסכמת הסתברות: האחוזים והשברים הם הצגה קריאה של תנאי `Random(n)`; כאשר `n` אינו
> מחלק את 32768 קיימת הטיית modulo זעירה כמפורט בפרק 2.

> תת-המערכת הגדולה במשחק. קוד: פרוצדורה מקוננת בתוך פרוצדורת-ההפלגה — כניסה `0x8D85`,
> גוף `0x97D8`; פרוצדורת הקרב `0x8F21`; עוזר נזק-קרב `0x8D98`; בוחר-סחורה `0x4883`;
> מו"מ `0x579A` (משותף עם פיתוי-הצוות). כל הנוסחאות אומתו בקוד.

## 1. מתי מופיעים שודדים (מפרק 6 §7)
בבורר אירועי-הדרך `R2=Random(20)+1`: ערכים 1–6 → שודדים (**30% ביום**); בלילה (שעה≥16) גם
16–20 ממופים ל-1 → **55% בלילה**. בעת המפגש מוצג מסך השודדים ומספר ספינות המשמר שלך.

## 2. ספינות המשמר
- נקנות ביציאה (פרק 6 §8): `מחיר = max(75,5×Trunc(רכוש/(200+Random(100))))`; בכל סיכון
  חיובי מתווסף שליש יחיד ואז המחיר נקטם לכפולה של 5.
- **מקסימום אפקטיבי: 3 ספינות משמר** (הקוד קוטם ל-3 בכל חישובי הקרב).

## 3. תפריט המפגש — שלוש ברירות
1. **להילחם** → קרב (§6).
2. **לברוח** → ניסיון בריחה (§4).
3. **להציע כופר** → מו"מ (§5).

## 4. בריחה (קוד `0x98C6`–`0x9AA7`) ✅
- אם `מטען > 0.81 × קיבולת` → הבריחה **בלתי אפשרית** (סיכוי 0).
- אחרת, שלב המהירות: `m = (קיבולת − מטען) / 30 + 1` (חלוקה שלמה, מינ' 1) —
  נכשל אם `Random(m) == 0`.
- עבר? שלב הנזק: נתפס אם `Random( נזק/30 + 1 ) > 0` (נזק 0 → לעולם לא נתפס בשלב זה).

> **P(בריחה) = (m−1)/m × 1/(נזק/30+1)**
> דוגמאות (קיבולת 100, ללא נזק): ספינה ריקה m=4 → 75% · מטען 50 m=2 → 50% · מטען 82+ → 0%.

הודעת כישלון לפי הסיבה: מטען>50% קיבולת → "ספינתך כבדה מדי"; נזק>0 → "לא הצלחת לברוח עקב
הנזק"; אחרת → "ספינת הפירטים המהירה הצליחה להשיג את ספינתך". **כישלון בריחה → קרב כפוי**,
בעמדת נחיתות (§6). הצלחה → "הצלחת להמלט מהם!!" והמסע נמשך.

## 5. כופר (קוד `0x9AF0`–`0x9BD8`) ✅
משתמש **באותה שגרת מו"מ `0x579A` של פיתוי-הצוות** (פרק 3 §6):
- **דרישת השודדים = רכוש ÷ (Random(6)+4)** — בין 1/9 ל-1/4 מהרכוש (מזומן+שווי מטען).
- השחקן מרכיב הצעה ממזומן וסחורה; ההצעה חייבת ≤ מה שברשותו.
- **הצעה > דרישה** → "שודדי הים החליטו לקבל את הצעתך" — משלמים והם עוזבים. שוויון נדחה.
- אחרת → "שודדי הים דוחים את הצעתך ותוקפים אותך!" → **קרב כפוי** בעמדת נחיתות (§6).

## 6. הקרב (פרוצדורה `0x8F21`) ✅
**עמדת נחיתות:** קרב שנכפה אחרי בריחה/כופר כושלים נלחם עם `G_eff = משמר − 1`
(הדגל מוחזר אחרי הקרב). קרב שנבחר ישירות: `G_eff = משמר`.

### 6.1 תנאי הניצחון
> **ניצחון ⇔ `Random(4) < G_eff` או (`G_eff ≤ 0` וגם `Random(6) == 1`)**

| משמר אפקטיבי | P(ניצחון) |
|---|---|
| 0 | 1/6 ≈ 16.7% |
| 1 | 25% |
| 2 | 50% |
| 3 (מקס') | 75% |

### 6.2 ניצחון — "הבסת את הפירטים!"
- **לכידת ספינתם:** `Random(3) == 1` (1/3) → "לקחת בשבי את ספינת שודדי הים" →
  **קיבולת += 50 טון** (`[0x2AD]`, קוד `0x9001`).
- **לכידה ומטמון הם מסלולים בלעדיים.** אם לא הייתה לכידה, מטמון:
  > **מטמון = Int(עושר/100)×(Random(15)+5) + עושר×משמר/10**
  > מינימום 100, נקטם לכפולת 5 — כלומר **5%–19% מהעושר הכולל (כולל הבנק!), +10% לכל ספינת
  > משמר**. מתווסף למזומן.
- המשמר שורד (מוחזר במלואו).

### 6.3 תבוסה
- **כל ספינות המשמר אובדות** ("ללא הגנת ספינות משמר, אתה הובסת" / "הפירטים התגברו על ספינת
  המשמר שלך" / "הפירטים ניצחו את N ספינות המשמר שלך").
- **ביזה** — השודדים בוחרים מה לגנוב: מזהים את **הסחורה היקרה ביותר** (`0x4883`:
  argmax של `cargo[c]×מחיר-מרכז[c]`), ומשווים את שוויה למזומן:
  - **שווי הסחורה > המזומן → גונבים מטען** ("אחרי קרב קשה גנבו ממך שודדי הים N טון"):
    > **נגנב = (Random(15)+5)% מהסחורה + (3−משמר)×10% ממנה** (מינ' 1 טון)
    > ללא משמר: 35%–49% מהסחורה היקרה! עם 3 משמר: 5%–19%.
  - **אחרת, אם מזומן > 500 → גונבים כסף** ("הם גנבו ממך N שקלים"):
    > **נגנב = ( Random(Trunc(1.5%×מזומן)) + מזומן/200 ) × 10 + (3−משמר)×מזומן/10**
    > ≈ 5%–20% מהמזומן, +10% לכל ספינת משמר חסרה.
  - מזומן ≤ 500 ואין סחורה יקרה → נזק ודאי מיוחד, מינימום 100, הכולל גם את הבנק.
- **נזק קרב** (עוזר `0x8D98(n)`): בהסתברות `1/n` — "לרוע מזלך, ספינתך נפגעה תוך כדי הקרב":
  > **נזק הסתברותי += 10×Trunc((Random(15)+5)×(מזומן+שווי-מטען)/1000)**; סיכויו 1/4
  > אחרי ניצחון ו־1/2 אחרי תבוסה רגילה. הבנק אינו נכלל.
  (מופעל גם בענף ניצחון כ"בנוסף, נגרם לספינה נזק".)

## 7. סיכום זרימת המפגש
```
מפגש (R2∈[1,6], 30%/55%)
├─ קרב ──────────────► ניצחון (Rnd4<G | 1/6) → 1/3 קיבולת+50 · מטמון 5–19%+10%×משמר
│                      תבוסה → אובדן כל המשמר · ביזה (מטען יקר/מזומן) · נזק אפשרי
├─ בריחה: מטען≤81%? → P=(m−1)/m×1/(נזק/30+1) → הצלחה=המשך · כישלון=קרב ב-G−1
└─ כופר: דרישה=רכוש/(Rnd6+4) → הצעה>דרישה=שילמת והלכו · אחרת (כולל שוויון)=קרב ב-G−1
```

> **אסטרטגיה מתמטית (נגזרת מהנוסחאות):** 3 ספינות משמר נותנות 75% ניצחון + מקטינות ביזה
> ל-5–19% + מגדילות מטמון ב-30% — ההשקעה הטובה במשחק. בריחה עדיפה רק בספינה ריקה ותקינה.
