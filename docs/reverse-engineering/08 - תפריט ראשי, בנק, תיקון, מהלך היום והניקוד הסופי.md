# פרק 8 — התפריט הראשי, הבנק, התיקון, מהלך היום והניקוד הסופי

> המפרט הסופי המחייב: [10 - מפרט מנוע מאומת סופית.md](10%20-%20מפרט%20מנוע%20מאומת%20סופית.md).

> הפרק הסוגר את המנוע: כל מה שמחוץ לאירועים ולהפלגה. כל הממצאים מאומתים בקוד.

## 1. אתחול משחק (קוד `0xC52C`–`0xC5C6`) ✅
| פרמטר | ערך התחלתי |
|---|---|
| מזומן `[0x2B9]` | **5000 ש"ח** (`0x1388`) |
| בנק `[0x2BF]` | 0 |
| מטען (3 סחורות) | 0 |
| נזק `[0x2B3]` | 0 |
| קיבולת `[0x2AD]` | 100 טון |
| מיקום `[0x281]` | **ישראל** |
| יום `[0x2AF]` | 1 · שעה `[0x2B1]` = 8:00 |
| יום סגירת הרציף `[0x2CE]` | `Random(7)+1` |
| יום סגירת הבנק `[0x2C5]` | `Random(7)+1` **ואז נדרס ל-0** (ראו §4) |
| אירוע-אתמול `[0x2C9]` | 0 |

## 2. השעון ומהלך היום ✅
- יום חדש (פרוצדורה `0xB52A`): **שעה := 8:00**, הרצת מנוע המחירים (`0x5FE5`), מזג אוויר,
  אירוע יומי (מיום 2), וביום 7 — אזהרת "יום המסחר האחרון… הנקודות על פי סכום הכסף".
- **השעון מתקדם +1 שעה לכל מקטע-מפה בתנועת הספינה** (קוד `0x8C48`, בתוך שגרת האנימציה
  `0x8ACF`). משך מסלול = מספר המקטעים במפת הניתוב (`[0x31F]`/`[0x364]`); מסלול
  **מצרים↔תורכיה** מקבל +4 שעות (עובר דרך אזור ישראל).
- הגעה משוערת אחרי 16:00 = הפלגת לילה (פרק 6 §1–2). "לנוח עד למחרת" = סיום היום.
- **הלולאה הראשית** (`0xCBD3`): בסוף כל יום `יום++`; כשהיום עובר את 7 — סוף המשחק (§6).

## 3. קנייה ומכירה (תפריט ראשי, אפשרויות 1–2) ✅
- מסך קנייה/מכירה לפי הנמל הנוכחי (`buyturk/buyisr/buyegpt` / `sell…`).
- מחיר = שער הסחורה בנמל (מנוע פרק 2 + זעזועים). **אין שום אקראיות בעסקה עצמה.**
- קנייה: עורך הקלט מחזיק `Real` פנימי אך מקבל רק ספרות 0–9, ולכן הכמות שלמה בפועל. העלות היא
  כמות×שער ולמלאי מתווסף `Trunc(כמות)`, הזהה לכמות הנגישה. **אין בדיקת קיבולת בקנייה**,
  והעונש הוא אירוע עומס-היתר בהפלגה (פרק 6 §5).
- מכירה: ההכנסה מחושבת דרך `Real` ומן המלאי נגרע `Trunc(כמות)`, אך מאחר שעורך הקלט אינו
  מאפשר נקודה עשרונית, ההתנהגות הנגישה היא מכירה של מספר טונות שלם.

## 4. הבנק (אפשרות 4) ✅
- **הפקדה:** הערך נשמר כ־`Real` ללא קיטום, אך עורך הקלט ספרתי בלבד; 0<סכום≤מזומן → בנק+=, מזומן−=.
  ("אין לך כסף להפקיד!", "אין לך כל כך הרבה כסף!")
- **משיכה:** סימטרית; גם כאן האחסון `Real` והקלט הנגיש שלם. ("אין לך כסף בבנק!", "אין לך סכום כסף כזה בבנק!")
- **אין ריבית ואין עמלה.** תפקיד הבנק: הגנה מפני גניבות-מזומן וביזת-שודדים (הבנק לא נפגע לעולם),
  והוא עשוי להיות רכיב תשלום באירוע ההרחבה (פרק 3 §5). כסף בבנק נספר בניקוד ובעושר-למטמון.
- **"הבנק סגור היום":** קיים בקוד שער `יום == [0x2C5]`, אבל האתחול **מאפס את `[0x2C5]`** מיד
  אחרי ההגרלה (קוד `0xC5A0`) → בפועל **הבנק לעולם אינו סגור** (קוד מת; ככל הנראה המפתח נטרל
  את הפיצ'ר). מסכי המשחק שבדקנו לא מציגים בנק סגור — עקבי.

## 5. תיקון הספינה (אפשרות 6) ✅
- אם `יום == [0x2CE]` (יום אקראי קבוע-למשחק) → "רציף התיקונים בנמל סגור היום - תאלץ להמתין
  עד מחר" — **יום אחד בשבוע הרציף סגור.**
- אחרת: מציג את הנזק, קלט סכום לתשלום (עד גובה המזומן) → מזומן−=כל הסכום,
  **נזק=max(0,נזק−סכום)**. תיקון־יתר מותר והעודף אובד.
- **בדיקת פשיטת רגל** (שגרה `0xB4E2`): אם `נזק > מזומן+בנק+שווי-מטען` → "אין באפשרותך לתקן
  את הנזק שנגרם לספינתך - ה מ ש ח ק   ה ס ת י ם!!" — **סוף משחק מיידי.**

## 6. סוף המשחק והניקוד ✅ (קוד `0xCBE5`)
- אחרי יום 7: **`ניקוד = מזומן + בנק`** — **המטען אינו נספר!** (לכן האזהרה למכור הכול ביום 7.)
- הניקוד מושווה לטבלת השיאים בקובץ **`WINNERS.WIN`** (רשומות של 27 בתים: שם + ניקוד Real);
  אם נכנסת לעשירייה — הזנת שם ("first_10.scr" למקום ראשון, "in_10.scr" לשאר).
- לבסוף: "האם אתה מעונין במשחק נוסף? (כ/ל)".

## 7. טבלת המרות סופית — כל משתני המצב

| `[0x2AF]` | יום (1–7) | | `[0x2C7]` | רמת סיכון הפלגה |
| `[0x2B1]` | שעה (8–…) | | `[0x2C9]` | אירוע אתמול |
| `[0x2B3]` | נזק (Real) | | `[0x2CD]` | דגל מפגע-במסע |
