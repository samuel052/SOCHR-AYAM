# פרק 9 — תוכנית הרימיקס המודרני של "סוחר הים"

> נוסחאות המנוע הסופיות נמצאות ב־[10 - מפרט מנוע מאומת סופית.md](10%20-%20מפרט%20מנוע%20מאומת%20סופית.md).

> מסמך התכנון הראשי. מבוסס במלואו על פרקי הפענוח 1–8 — שם נמצא המפרט המחייב של כל נוסחה.
> מסמך זה קובע: עקרונות, ארכיטקטורה, מפרט-מנוע מאוחד (פסאודו-קוד), מיפוי מסכים, שלבי ביצוע
> ושיטת אימות מול המקור.

---

## 1. חזון ועקרונות

**החזון:** גרסה מודרנית של "סוחר הים" — נגישה, יפה ונוחה — שמשחזרת **אחד-לאחד** את חוויית
המשחק המקורית: אותם אירועים, אותם סיכויים, אותן נוסחאות.

**עקרונות מחייבים:**
1. **נאמנות למקור כברירת מחדל.** כל הגרלה ונוסחה — בדיוק כפי שפוענחו (פרקים 2–8). שינויי
   איזון, אם יהיו, רק כמצב משחק נפרד ומסומן.
2. **הפרדה מוחלטת מנוע/תצוגה.** המנוע = ספריית לוגיקה טהורה (ללא UI, ללא I/O), דטרמיניסטית
   בהינתן זרע — מה שמאפשר בדיקות אוטומטיות מול המפרט.
3. **RNG מוזרק.** ברירת המחדל היא ה־LCG האותנטי של TP3
   (`seed×129+0x361962E9`, `Random(n)=(hi>>1) mod n` — פרק 2). RNG מודרני נשאר חלופה מפורשת.
4. **עברית RTL מלאה**, כולל המספרים בכיוון הנכון (תיקון עיוות ה-DOS המקורי).

|---|---|---|

## 3. מפרט המנוע המאוחד — פסאודו-קוד מחייב

> זהו "החוק". כל סעיף מפנה לפרק שבו הנוסחה פוענחה ואומתה.

### 3.1 קבועי פתיחה (פרק 8 §1)
```
מזומן=5000 · בנק=0 · מטען=[0,0,0] · נזק=0 · קיבולת=100 · מיקום=ישראל
יום=1 · שעה=8 · יום_רציף_סגור=Random(7)+1 · אירוע_אתמול=אין
מרכזי מחיר: נחושת 3000, זיתים 500, חיטה 50 (קבועים)
```

### 3.2 מחזור היום (פרקים 2–3, 8)
```
לכל יום 1..7:
  שעה := 8
  # מחירים (פרק 2): לכל נמל ולכל סחורה, הגרלה עצמאית:
  מחיר[נמל][נחושת] = 2500 + Random(11)×100
  מחיר[נמל][זיתים] = 350  + Random(7)×50
  מחיר[נמל][חיטה]  = 35   + Random(8)×5
  # מזג אוויר (פרק 3 §1): יום 1 רגוע; אחרת:
  אם Random(8) < 3: נמל_סוער = Random(3)+1  אחרת: אין סערה
  # אירוע יומי (פרק 3) — רק מיום 2:
  חזור-על:
    R = Random(30)+1
    אם זוג(R) == זוג(אירוע_אתמול): המשך-הגרלה            # 15 זוגות: 1–2 ... 29–30
    אם מזומן>20000 ו-Random(6)==1: R := 15
    אם מזומן>45000 ו-Random(6)==1: R := 15                # שתי ההגרלות נצרכות תמיד
    אירוע = בצע-אירוע(R)
    אם האירוע אינו ישים: המשך-הגרלה                       # חוזר לכל הבורר
    השלם בחירה/תצוגה; אירוע_אתמול := R; צא
  ... פעולות השחקן (תפריט) ...
  בסוף היום: יום++
אחרי יום 7: ניקוד = מזומן + בנק → טבלת שיאים
```

### 3.3 טבלת האירועים (פרק 3 §3–9, פרק 4)
| R | אירוע | הנוסחאות |
|---|---|---|
| 1–12 | זעזוע מחיר | נמל=Rnd(3)+1; נחושת ±(1100+Rnd(5)×100) · זיתים ↑200+Rnd(4)×50, ↓150+Rnd(3)×50 · חיטה ↑20+Rnd(5)×5, ↓15+Rnd(3)×5 |
| 13–18 | הרחבת ספינה | +（Rnd(2)+1)×50 טון; פירוק תשלום מזומן/בנק/מטען לפי פרק 10 |
| 19–20 | נטישת צוות (ימים 2–5 בלבד, אחרת הגרלה מחדש) | פיתוי: דרישה=(מזומן+שווי מטען)/(Rnd(6)+4); הצעה ממזומן+סחורה; אחרת אובדן יום |
| 21–22 | גניבה | מזומן תחילה: 10×Trunc(מזומן/(40+Rnd40)); רק תוצאת 0 עוברת למטען 20–40% |
| 23–26 | סוחר קונה ממני | מחיר: נחושת שוק+Rnd(30)×50−600 · זיתים שוק+Rnd(70)×10−300 · חיטה שוק+Rnd(14)×5−40 |
| 27–28 | סוחר מוכר לי | סחורה=Rnd(3)+1; `B=.25×מזומן+Rnd(Trunc(.75×מזומן)+1)`; כמות=`5×Trunc((B/מרכז)/5+1)` |
| 29–30 | התנגשות | נזק += `10×Trunc((מזומן+שווי מטען)/(Rnd(80)+150))`; אפס גורם reroll |

### 3.4 הפלגה (פרק 6 — הפסאודו-קוד המלא שם) — תמצית:
```
סיכון = יום:0 / יום+סערה:3 / לילה:2 / לילה+סערה:4   (סערה=נמל_סוער∈{מוצא,יעד})
k = 1 + Trunc((נזק+399)/400) + 2×סיכון
מפגע ⇔ Random(k)>0 ו-Random(2)==1
  → נזק>0: החמרה · אחרת 1/3: סערה/שרטון · 2/3: סטיית-ניווט (ישראל→תורכיה, אחרת→ישראל)
בלי מפגע: עומס (אם מטען>קיבולת, P=1/k לפי עודף) → ערפל/שביתה (1/12, ואז 50/50) →
R2=Random(20)+1: 1–6 שודדים (לילה: גם 16–20) · 7 ניווט · 9–10 ספינה נטושה · אחרת שקט
```

### 3.5 שודדי ים (פרק 7) — קרב/בריחה/כופר, כל הנוסחאות שם.
### 3.6 בנק/תיקון/מסחר/ניקוד (פרק 8) — כולל: אין ריבית; רציף סגור יום בשבוע; 1 ש"ח=1 נזק;
פשיטת רגל אם נזק>מזומן+בנק+שווי מטען; קנייה בלי בדיקת קיבולת; ניקוד=מזומן+בנק.

│   ├── voyage.ts          # כל שלבי ההפלגה (פרק 6)
│   ├── pirates.ts         # פרק 7
│   ├── bank.ts, repair.ts, trade.ts, scoring.ts   # פרק 8

## 6. הבטחת נאמנות — בדיקות

1. **בדיקות יחידה** לכל נוסחה (טווחים, קצוות: מחיר∈[2500,3500] וכו').
2. **בדיקות התפלגות (מונטה-קרלו):** מיליון הגרלות לכל מנגנון והשוואה להתפלגות התאורטית
   מהפרקים (למשל: זעזוע 40% מהימים, שודדי-לילה 55%, בריחה בספינה ריקה 75%).
3. **מצב RNG אותנטי:** הרצת תרחיש עם זרע נתון והשוואת רצף ההגרלות לסימולטור ה-LCG
   (`tools/tpreal.py`/`randmap` כבר נותנים תשתית).
4. **בדיקת רגרסיה מול המקור:** משחק מקביל ב-DOSBox מול הרימיקס באותם מצבים ידניים
   (מחירים, אירועים) — אימות איכותני אחרון.

## 7. שיפורי UX (לא נוגעים בלוגיקה)
- שמירה/טעינה; יומן קפטן (לוג אירועים); טבלת מחירים היסטורית של השבוע.
- אישורי פעולה ברורים; הצגת שעת-הגעה משוערת לפני הפלגה (המידע קיים במקור בעקיפין).
- נגישות: מקלדת מלאה, גדלי גופן.
- **"מצב גילוי" (אופציונלי, כבוי כברירת מחדל):** הצגת הסיכויים האמיתיים — פרי הפענוח —
  לסקרנים. (משנה את חוויית המשחק, לכן אופציונלי.)

## 8. תוספות עתידיות (מצב "מודרני", לא בגרסה 1)
- החזרת "הבנק הסגור" לחיים (הפיצ'ר המנוטרל שגילינו — קוד מת במקור!).
- איזונים, קושי מדורג, ימים 10/14, סחורה רביעית — הכול מחוץ למצב הקלאסי.
