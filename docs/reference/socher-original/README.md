# חומר מקור — "סוחר הים" (Socher HaYam)

חומר הרפרנס לבניית הרימייק של משחק ה‑DOS הקלאסי **סוחר הים**. כל מה שכאן הוא
**מקור/רפרנס בלבד** — לא ה‑GDD‑ים ולא הנכסים של הפרוייקט עצמו. הוא ממוקם תחת
`docs/reference/` בכוונה, כדי שכלי הסטודיו (`/design-review`, `/asset-audit`)
לא ינסו לוודא אותו כתוצר סופי. כשנחבר GDD‑ים רשמיים, הם יצטטו את המסמכים כאן.

## תמצית המשחק

סוחר מפליג בין שלושה נמלים בים התיכון — **חיפה** (ישראל), **פורט‑סעיד** (מצרים),
**מרסין** (תורכיה) — קונה ומוכר שלוש סחורות (**נחושת, זיתים, חיטה**) לאורך
**7 ימי עבודה**, תוך התמודדות עם סערות, שודדי ים, גניבות ותקלות הפלגה. המטרה:
לסיים עם כמה שיותר מזומן. התחלה: ספינה בקיבולת 100 טון ו‑5000 ש"ח.

## שני מפלסי מקור — חשוב להבחין

יש כאן **שני סוגי מסמכים** שלא תמיד מסכימים זה עם זה:

| מפלס | מה זה | סמכות |
|------|-------|-------|
| **מפרט הרימייק** | `תוכנית.txt` + `מנגנון-אירועים/התפלגות סיכויים.txt` — כוונת העיצוב של הרימייק | **סמכותי** לרימייק |
| **פענוח המקור** | שאר `מנגנון-אירועים/*.txt` — הנדסה‑לאחור של הבינארי המקורי (Turbo Pascal COM) | תיאור המקור, לא בהכרח מה נבנה |

כשיש סתירה בין נוסחה מפוענחת לבין `התפלגות סיכויים.txt` — **`התפלגות סיכויים.txt`
גובר** לצורך הרימייק. הפענוח שימושי להבנת ההתנהגות המקורית ולמילוי פערים, אבל
מסמך התפלגות הסיכויים סוגר במפורש כמה דברים שהפענוח השאיר "פתוחים" (ספינה נטושה,
השלכת מטען עודף, יעד טעות‑ניווט, מחירי ספינות משמר, סגירת רציף תיקונים).

## מבנה התיקייה

```
docs/reference/socher-original/
├── README.md                      # הקובץ הזה
├── תוכנית.txt                     # תוכנית המשחק המלאה (תמה, מהלך, תרחישים)
├── אפיון מסכי משחק.docx            # אפיון מסכי המשחק
├── מנגנון-אירועים/                # ניתוח מנועי המשחק (מפרט + פענוח)
│   ├── התפלגות סיכויים.txt         # ★ מפרט הסיכויים והנוסחאות הסמכותי לרימייק
│   ├── תיאור כללי אירועי הפלגה.txt # תיאור נגיש של סכנות ההפלגה
│   ├── סיכום אירועי הפלגה.txt      # פענוח מנוע ההפלגה
│   ├── סיכום אירועי הפלגה מהודק.txt# פענוח מנוע ההפלגה (גרסה מהודקת/אלגוריתמית)
│   ├── סיכום מנוע אירועי בוקר.txt  # פענוח מנוע אירועי הבוקר (30 קודים)
│   ├── סיכום שודדי ים.txt          # פענוח תרחיש שודדי הים
│   └── אירוע רוחות.txt             # פענוח אירוע הרוחות / טעות בניווט (change)
├── original-build/                # המשחק המקורי — קבצים בינאריים + טקסטים גולמיים
│   ├── socher1/                   # ה‑build של DOS
│   │   ├── *.COM, *.BAT, *.DAT    # הרצה: גופנים עבריים, מקלדת, אתחול
│   │   ├── קבצי SCR/              # 20 מסכי .SCR + תרגום/ (טקסט מפוענח)
│   │   ├── קבצי SGN/              # 14 קבצי .SGN + תרגום/
│   │   └── קבצי WIN/              # 26 חלונות .WIN + תרגום/
│   ├── SOCHER/                    # חומר נוסף מהמקור
│   └── *.txt                      # טקסטים גולמיים שחולצו (K, OFFER, PIRATES)
├── screenshots/                   # ~90 צילומי מסך מהמקור, ממוינים לפי פעולה/אירוע
└── mockups/                       # 3 תמונות קונספט (Gemini) לכיוון ויזואלי
```

## מפת מנגנונים → קבצים (לכתיבת GDD בהמשך)

- **מחירים רגילים ומיוחדים** → `התפלגות סיכויים.txt` §מחירים, `סיכום מנוע אירועי בוקר.txt` §9
- **מנוע אירועי בוקר** (מחיר/סוחר/הגדלה/שביתה/גניבה/דיג) → `סיכום מנוע אירועי בוקר.txt`, `התפלגות סיכויים.txt`
- **מנוע הפלגה** (שער סיכונים, סערה, שרטון, מטען עודף, ערפל/שביתה) → `סיכום אירועי הפלגה מהודק.txt`, `התפלגות סיכויים.txt` §הפלגה
- **שודדי ים** (קרב/בריחה/פשרה, ספינות משמר) → `סיכום שודדי ים.txt`, `התפלגות סיכויים.txt` §אירוע שודדי ים
- **טעות בניווט / רוחות** → `אירוע רוחות.txt`, `התפלגות סיכויים.txt`
- **מסכי UI / זרימת מסכים** → `אפיון מסכי משחק.docx`, `original-build/socher1/קבצי SCR|WIN|SGN/`, `screenshots/`

## הערות תחזוקה

- **קידוד:** `התפלגות סיכויים.txt` הומר מ‑Windows‑1255 (CP1255) ל‑UTF‑8 כדי שיהיה
  קריא ו‑greppable. שאר מסמכי הטקסט כבר היו UTF‑8.
- **שמות עבריים:** שמות הקבצים המקוריים בעברית נשמרו (נושאי משמעות); רק
  הקונטיינרים (`original-build`, `screenshots`, `mockups`) באנגלית.
- כל ההעברה בוצעה עם `git mv` — ההיסטוריה נשמרת.
