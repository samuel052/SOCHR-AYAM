## Purpose & Player Need

הבית של המשחק: השחקן מגיע לכאן אחרי כל הכרזת בוקר, קניה, מכירה או הפלגה, וממנו
יוצא לכל פעולה. "אני רוצה לראות את מצבי במבט אחד ולבחור את הצעד הבא בקליק אחד."
מחליף את תפריט 5–6 האפשרויות של המקור בנמל חי ולחיץ.

## Player Context on Arrival

- בתחילת יום (אחרי כרטיסי ההכרזה) — סקרן/מחושב: "מה המחירים היום?"
- אחרי הפלגה — נרגש או חבול (אירוע ים) ומיד בודק את הפאנלים.
- מגיע תמיד באופן אוטומטי; זה מסך ברירת המחדל.

## Navigation Position

root ← title ← **port-hub**. יעד־העל היחיד; כל שאר המסכים בעומק 1 ממנו (ADR-0007).

## Layout Specification

### Information Hierarchy

1. הנמל עצמו והפעולות (מרכז) 2. פאנל מצב (ימין, HUD) 3. ‏Price Board (תחתון, HUD)
4. ‏Info Bar (עליון, HUD) — הכול מוגדר ב־hud.md; מסך זה מספק את אזור המרכז.

### Layout Zones + Component Inventory

אזור מרכזי: ציור נמל פיקסל־ארט (בהשראת `עיצוב/`), אחת משלוש וריאציות תרבותיות
(ישראלי/תורכי/מצרי — `אפיון מסכי משחק.docx`), ובו hotspots ‏(P1):

| Hotspot | ייצוג חזותי | פעולה | פעיל |
|---|---|---|---|
| שוק הקניה | דוכנים בשוק | → market (buy) | תמיד |
| כיכר המכירה | סוחר מכריז + קונים | → market (sell) | תמיד |
| בנק | מבנה בנק | → bank | תמיד |
| רציף תיקונים | מספנה + פיגומים | → repair-dock | נזק>0 |
| לוח מודעות | לוח עץ עם דפים | → notice board overlay | תמיד |
| המזח / הספינה | ספינת השחקן עוגנת | → voyage map | נזק≤1,000 |
| פונדק | דלת פונדק מוארת | → מנוחה (Confirm ביום 7 / כשיש סחורה) | תמיד |

הספינה בנמל משקפת מצב: עמוסה/ריקה, תקינה/פגועה (עשן/קרש שבור) — לפי docx.

## States & Variants

| מצב | טריגר | שינוי |
|---|---|---|
| Default | — | לפי הנמל הנוכחי (3 וריאציות) |
| נזק קל | 0<damage≤1000 | רציף לחיץ; ספינה פגועה חזותית |
| חסום להפלגה | damage>1000 | מזח מעומעם + ⚠ "יש לתקן תחילה"; רציף מודגש |
| עומס יתר | cargo>capacity | הספינה שקועה נמוך במים; ⚠ בפס המטען |
| סערה היום | storm_port≠none | שמיים מעוננים בנמל הסוער (אם זה הנמל הנוכחי) |
| יום 7 | day==7 | שלט "יום אחרון!" עדין ליד הפונדק |

## Events Fired

| פעולה | פקודת GameFacade | הערות |
|---|---|---|
| פונדק (מנוחה) | `rest()` | משנה מצב מתמיד; אוטוסייב בתחילת יום (ADR-0004) |
| שאר ה־hotspots | ניווט בלבד | אין שינוי מצב |

## Transitions & Animations

כניסה: fade 200ms מהכרטיס האחרון. יציאה למסכי פעולה: slide קצר לכיוון ה־hotspot.
אנימציות אווירה (גלים, דגלים, נוסעים) — קוסמטיות, כבויות ב־reduced-motion.

## Data Requirements

הכול דרך snapshot של GameFacade (קריאה בלבד): port, day, clock, damage, cargo,
capacity, storm_port, prices. אין כתיבה מהמסך פרט ל־`rest()`.

## Accessibility

- מסלול מקלדת: Tab עובר בין hotspots בסדר 1–6, ‏Enter מפעיל; focus ring ברור.
- כל hotspot עם תווית טקסט; חסימות עם טולטיפ מוסבר.

## Localization Considerations

תוויות hotspot קצרות (≤12 תווים); שמות נמלים מהטבלה. אנגלית עתידית: פריסה
תתהפך ל־LTR אוטומטית (root layout) — הפאנל יעבור לשמאל; אין תלות בקואורדינטות קשיחות.

## Acceptance Criteria

- [ ] המסך נטען ≤100ms אחרי סגירת הכרטיס האחרון.
- [ ] כל 7 ה־hotspots מפעילים את היעד הנכון בעכבר וגם במקשים 1–6.
- [ ] נזק>1,000: המזח חסום עם הסבר, והרציף מודגש; תיקון ל־≤1,000 משחרר מיד.
- [ ] רציף מופיע לחיץ רק כש־damage>0 (TR-SHIP-03).
- [ ] מנוחה ביום 7 מציגה אישור וסוגרת את המשחק לרצף הסיום.
- [ ] מסלול מקלדת מלא מגיע לכל האלמנטים בסדר הגיוני עם focus נראה.
