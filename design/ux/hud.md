## HUD Philosophy

"הכול גלוי, כמו במקור — אבל מסודר." המשחק תורני וקבלת ההחלטות היא כל המשחק,
לכן כל נתון רלוונטי להחלטה גלוי תמידית (כמו במסך המקורי: פאנל ימין + לוח
מחירים תחתון). אין ערפול מידע; מסך F10 של המקור מתבטל כי תוכנו נבלע ב־HUD
(שיפור UX מאושר — לא משנה לוגיקה).

## Information Architecture

### Full Information Inventory + Categorization

| מידע | מקור (GDD) | קטגוריה |
|---|---|---|
| מדינה נוכחית, יום, שעה | time-calendar | **Must Show** — Info Bar |
| מזג אוויר היום (נמל סוער אם יש) | morning-events | **Must Show** — Info Bar |
| קיבולת + סה"כ מטען (עומס!) | ship, trading | **Must Show** — Info Bar |
| מצב ספינה (תקינה / נזק בש"ח / חסומה>1000) | ship-damage-repair | **Must Show** — Info Bar |
| מלאי 3 הסחורות | trading | **Must Show** — פאנל צד |
| מזומן | trading | **Must Show** — פאנל צד |
| יתרה בבנק | banking | **Must Show** — פאנל צד |
| מחירי 3×3 | market-prices | **Must Show** — Price Board תחתון |
| כפתור הגדרות/תפריט | — | **Must Show** — אייקון קבוע |
| פירוט אירוע היום | morning-events | **Contextual** — לוח המודעות בנמל |
| ספינות משמר פעילות | pirates | **Contextual** — רק במסך ההפלגה |

בדיקת עומס מול הפילוסופיה: ‏~11 פריטים, תואם "הכול גלוי" ותואם 1:1 את מסך המקור.

## Layout Zones

RTL — היררכיה מימין לשמאל (ADR-0006). רזולוציית עיצוב 640×360 (ADR-0005).

```text
┌──────────────────────────────────────────────────────────────┐
│ INFO BAR: [יום א' | 08:00] [ישראל] [מזג אוויר] [ספינה] [⚙]  │ ← עליון
├────────────────────────────────────────────────┬─────────────┤
│                                                │ פאנל מצב:   │
│              אזור המסך הפעיל                    │ נחושת  X    │
│        (נמל / שוק / הפלגה / דיאלוגים)           │ זיתים  X    │
│                                                │ חיטה   X    │
│                                                │ מזומן  X    │
│                                                │ בנק    X    │
├────────────────────────────────────────────────┴─────────────┤
│ PRICE BOARD: תורכיה | ישראל | מצרים  ×  נחושת/זיתים/חיטה     │ ← תחתון
└──────────────────────────────────────────────────────────────┘
```

הפאנל בצד **ימין** — נאמן למסך המקור (הפרטים היו בימין). ‏Price Board בתחתית —
כמו במקור.

## Dynamic Behaviors

- ה־HUD קבוע בכל המסכים למעט: מסך הפתיחה, מסכי הסיום/שיאים, ואנימציית ההפלגה
  (שם Info Bar נשאר אך הפאנלים מוסתרים לטובת הסצנה — נשקל בפלייטסט).
- כשמודאל פתוח ה־HUD גלוי אך אינו אינטראקטיבי (P8).
- שינויי ערכים תמיד מונפשים מהערך הישן לחדש (200ms count) — כבוי ב־reduced-motion.

## Platform & Input Variants

פלטפורמה אחת (Windows). ‏hover-tooltips לכל אייקון; ניווט מקלדת אינו נכנס
ל־HUD (תצוגה בלבד) פרט לכפתור ⚙.

## Accessibility

- כל אייקון מלווה טקסט; אזהרות עם ⚠; ניגודיות לפי accessibility-requirements.
- "טקסט גדול" מגדיל את ה־HUD ב־×1.25 (הפריסה בנויה לכך).
