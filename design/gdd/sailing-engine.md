# GDD — מנוע הפלגה ואירועי ים (sailing-engine)

> שכבה: Core | סטטוס: Draft | מקור אמת: `סיכום אירועי הפלגה מהודק.txt`, `אירוע רוחות.txt` (פיענוח); מילויי פערים: `התפלגות סיכויים.txt` ⚠️
> מוסכמה: `rand(n)` = שלם אחיד `0..n-1`; חלוקה שלמה = קיטום.

## 1. Overview

ההפלגה היא הפעולה היחידה שמקדמת את הזמן — וגם מקור הסיכון המרכזי. לפני היציאה עוברת ההפלגה "מעטפת": בחירת יעד, הצעת ספינות משמר, אזהרות עומס ולילה. במהלכה מתרחש **לכל היותר אירוע אחד**, שנבחר בארבע שכבות בדיקה סדורות: שער הסיכונים המיוחדים ← עומס יתר ← ערפל/שביתה בנמל היעד ← טבלת האירועים הרגילים (פיראטים, רוחות, ספינה נטושה, הגעה בשלום).

## 2. Player Fantasy

לצאת לים זה הימור מחושב: ים פתוח, שעון מתקתק, והידיעה שכל מסע יכול להסתיים במטמון, בפיראטים או בחזרה מבישה לנמל המוצא. ההכנות (משמר? להמתין לבוקר? לפרוק עודף?) הן חלק מהמשחק לא פחות מהמסע עצמו.

## 3. Detailed Rules

### 3.1 מעטפת ההפלגה (לפני מנוע האירועים)

1. בחירת יעד (אחד משני הנמלים האחרים) וחישוב זמן (`time-calendar.md`).
2. בדיקות זמן: תסתיים אחרי 20:00 ⇒ חסימה; אחרי 16:00 ⇒ אזהרת לילה + אישור שחקן.
3. נזק > 1,000 ⇒ חסימה (`ship-damage-repair.md`).
4. הצעת רכישת ספינות משמר (0 עד N, במזומן). מחיר ⚠️ (מקור: אפיון בלבד):
   `guard_price = max(75, trunc(0.02 * ship_value))` לספינה; ‏+50% אם סערה בנמל המוצא או היעד; ‏+25% אם הפלגה לילית; מצטבר. תוקף המשמר: להפלגה הנוכחית בלבד ⚠️ (הנחת עבודה, נתמכת בכך שההצעה חוזרת לפני כל הפלגה).
5. אם `cargo_total > capacity` ⇒ אזהרת עומס יתר + אישור שחקן.
6. יציאה ⇒ מנוע האירועים רץ פעם אחת וקובע את תוצאת המסע.

### 3.2 מבנה מנוע האירועים — ארבע שכבות (אירוע אחד לכל היותר)

```text
1. שער הסיכונים המיוחדים  → אם נכנס: רוחות/סערה/שרטון/נזק-מוחמר (לפי סדר)
2. עומס יתר / שקיעה       → אם לא היה אירוע וקיימת חריגה
3. ערפל / שביתה ביעד      → אם לא היה אירוע
4. טבלת אירועים רגילים    → rand(20)+1
```

### 3.3 שכבה 1 — שער הסיכונים המיוחדים

- `N = 2*class + 1 + trunc((damage + 399) / 400)` — ‏class הוא קוד מצב פנימי של ההפלגה ⚠️ (משמעותו המדויקת לא פוענחה; הנחת עבודה: מדרגת מצב המשלבת לילה/סערה, תיבדק ב־DOSBox).
- כניסה לשער: `rand(N) > 0` **וגם** `rand(2) == 1` ⇒ ‏`P = ((N−1)/N) · ½` — תמיד מתחת ל־50%; נזק קיים מעלה את N ולכן את הסיכוי.
- בתוך השער, סדר הכרעה: רוחות ← סערה ← שרטון ← נזק־מוחמר. תנאי כל אחד:
  - **סערה**: רק אם נמל המוצא או היעד תחת סערת היום.
  - **שרטון**: רק בהפלגה לילית (אחרי 16:00). סערה נבדקת לפניו וגוברת עליו.
  - **נזק־מוחמר**: רק אם `damage > 0`.
- ⚠️ שני דגלים פנימיים בתחילת השער לא פוענחו — יאומתו ב־DOSBox; עד אז המימוש יעקוב אחרי הסדר המתועד בלבד.

### 3.4 סערה (storm)

1. `cargo_value = Σ qty·market_price` (מחירי נמל המוצא).
2. אם `cargo_value > 10000` ⇒ **סערת מטען**: נבחרת הסחורה הראשונה בסדר קבוע (נחושת←זיתים←חיטה) שכמותה >2 טון;
   `loss = trunc(qty * (4*rand(21)) / 100)`, קלמפ ‎[1, qty]‎ — אובדן 0%–80% בקפיצות 4%.
   טקסט מקור: "הגלים הגבוהים שטפו מספינתך [כמות] טון [סחורה]".
3. אחרת ⇒ **סערת נזק**: מנגנון הנזק הכללי (§3.7).

### 3.5 שרטון (sirton)

פתיח ("בלילה - עלית על שרטון... עקב תנאי הראות הגרועים") + מנגנון הנזק הכללי (§3.7).

### 3.6 נזק־מוחמר (damaged בהפלגה פגועה)

מפליגים עם `damage > 0` ⇒ ייתכן נזק נוסף דרך מנגנון הנזק הכללי. טקסט: "הנסיעה בספינתך הניזוקה החמירה...".

### 3.7 מנגנון הנזק הכללי (משותף לסערה/שרטון/נזק־מוחמר)

```text
TotalValue = cash + cargo_value            # ללא בנק
dmg = 5 * trunc( TotalValue / (rand(100)+200) )   # מחלק 200..299
if dmg < 75: dmg = 75
if damage > 0: dmg = dmg + trunc(dmg/3)    # +שליש לספינה שכבר פגועה
dmg = 5 * trunc(dmg / 5)                   # יישור לכפולות 5
damage += dmg
```

מינימום מעשי: 75 לספינה תקינה, 100 לפגועה.

### 3.8 שכבה 2 — עומס יתר / שקיעה

רק אם לא אירע דבר בשכבה 1 ו־`cargo_total > capacity`:

```text
over = cargo_total - capacity
P(שקיעה): over ≤ 20 → 1/6 | 21–40 → 1/4 | 41–60 → 1/3 | 61–70 → 1/2 | over > 70 → ודאי
```

בשקיעה: הודעה + השלכת סחורה אוטומטית (ללא בחירת שחקן), וזה האירוע היחיד של ההפלגה.
⚠️ **פער**: סוג וכמות ההשלכה לא פוענחו. מילוי (אפיון): מושלכת הסחורה שערכה הכולל הגבוה ביותר, בכמות `rand(trunc(qty/2))+1` (‏1 עד מחצית הכמות). לאימות DOSBox. הנחת השלמה: אם לאחר ההשלכה עדיין `cargo > capacity` — אין השלכה נוספת (אירוע אחד להפלגה).

### 3.9 שכבה 3 — ערפל / שביתה בנמל היעד

- אירועי כניסה לנמל: אי אפשר לעגון ⇒ חזרה לנמל המוצא; הזמן נספר פעמיים (הלוך+חזור).
- ⚠️ **פער**: הסתברות הכניסה לענף זה לא פוענחה. מילוי (אפיון, מותאם): הגרלה ייעודית לפני הטבלה הרגילה; ‏50/50 בין ערפל לשביתה. פרמטר `port_block_chance` ב־config יכויל באימות DOSBox; ערך פתיחה: 1/15 (משוקלל כך שסך "חסימת נמל" בהפלגה ~5%, ברוח יחסי האפיון).
- בהפלגה חוזרת לאותו יעד הכול מוגרל מחדש — החסימה אינה "מצב נמל" מתמשך.

### 3.10 שכבה 4 — טבלת האירועים הרגילים

```text
n = rand(20) + 1
1–6   → פיראטים (30%)            # ראו pirates.md
7     → רוחות / טעות ניווט (5%)
8     → הגעה בשלום
9–10  → ספינה נטושה (10%)
11–20 → הגעה בשלום               # סה"כ בשלום: 55%
```

⚠️ בהפלגה לילית קיימת הטיה נוספת שמקטינה תוצאות "שקטות" — מיפויה לא נסגר; ייבדק ב־DOSBox. עד אז: ללא הטיה.

### 3.11 רוחות / טעות ניווט (change)

- כלל ההסטה (מקור: `אירוע רוחות.txt`): יעד מקורי ישראל ⇒ מגיעים לתורכיה; כל יעד אחר ⇒ מגיעים לישראל.
- זמן: ללא תוספת, פרט למקרה היחיד מוצא=מצרים ויעד־חדש=תורכיה (כלומר מצרים→ישראל שהוסטה) ⇒ ‏+4 שעות.
- אוטומטי לחלוטין: אין בחירה, אין נזק, אין אובדן. הודעה: "כתוצאה מרוחות חזקות וטעות בניווט, הגעת ל[X] במקום ל[Y]".
- הערה: הסטה ליעד זהה למוצא אינה אפשרית בכללים אלה (המוצא לעולם אינו היעד המקורי, והכלל ממפה רק ליעדים ישראל/תורכיה) — למעט תורכיה→ישראל שמוסטת לתורכיה = חזרה למוצא; אז הזמן נשאר כמתוכנן (`תוכנית.txt`: חזרה למוצא בטעות ניווט = זמן זהה למתוכנן).

### 3.12 ספינה נטושה (deserted)

⚠️ **פער**: האלגוריתם לא פוענח. מילוי (אפיון):
1. סחורה מוגרלת שווה־סיכוי (1/3).
2. `total = ship_value(origin_port)` ‏(מטען במחירי המוצא + מזומן).
3. `value = rand(total - 100 + 1) + 100` ‏(100 עד total).
4. `qty = ceil(value / price[destination_port][good])` — עיגול כלפי מעלה.
5. הסחורה מתווספת למטען (עשויה ליצור עומס יתר לקראת ההפלגה הבאה).
לאימות DOSBox.

## 4. Formulas

מרוכזות בסעיף 3 (המנוע הוא רצף החלטות; הנוסחאות מוצמדות לשלבים). כללי עזר:

```text
cargo_value(port) = Σ cargo[good] * price[port][good]
ship_value(port)  = cargo_value(port) + cash
night_sail        = arrival_time > 16:00
storm_exposure    = storm_port ∈ {origin, destination}
```

## 5. Edge Cases

- כל השכבות שקטות ⇒ "הגעת בשלום!!" — תוצאה מפורשת, לא ברירת מחדל שקטה.
- הפלגה עם עומס + לילה + נזק + סערה בו־זמנית: הסדר הדוקומנטרי מכריע — שער הסיכונים קודם (ובתוכו סערה לפני שרטון), עומס אחריו.
- ספינה נטושה שמוסיפה מטען מעל הקיבולת — אין שקיעה באותה הפלגה (האירוע כבר קרה); הסיכון נדחה להפלגה הבאה.
- רוחות בהפלגת לילה: זמן ההגעה נשאר כמחושב (למעט +4 של המקרה היחיד) — ההגעה עשויה להידחות מעבר ל־20:00; מותר (רק היציאה מוגבלת).
- חזרה בשל ערפל/שביתה שמנחיתה את השחקן אחרי 20:00 — חוקית; היום למעשה הסתיים והשחקן ינוח.
- סערת מטען כשאין אף סחורה >2 טון: ⚠️ לא פוענח; הנחת עבודה: נופלים לסערת נזק (המסלול השני), לאימות.
- עומס יתר עם over>70 — שקיעה ודאית; המימוש חייב לכסות את הענף הדטרמיניסטי בבדיקה.
