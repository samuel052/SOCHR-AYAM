# GDD — מסחר: קניה ומכירה (trading)

> שכבה: Core | סטטוס: Draft | מקורות: `תוכנית.txt`, צילומי מסך `לקנות/`, `למכור/`
> מוסכמה: `rand(n)` = שלם אחיד `0..n-1`.

## 1. Overview

מערכת הקניה והמכירה בנמל: השחקן קונה סחורה במחיר הנמל הנוכחי (מוגבל בכסף המזומן) ומוכר סחורה מהמטען (מוגבל בכמות שברשותו). אין הגבלת קיבולת על קניה — מותר להעמיס מעבר לקיבולת, על אחריות השחקן (סיכון שקיעה בהפלגה). הפעולות אינן צורכות זמן וזמינות בכל שלב ביום.

## 2. Player Fantasy

סוחר ממולח שסופר כל שקל: לקנות בזול, למכור ביוקר, ולדעת מתי להעמיס את הספינה עד (ומעבר) לגבול. תחושת שוק חופשי פשוטה וישירה — בלי עמלות, בלי חיכוך, רק מחיר וכמות.

## 3. Detailed Rules

1. קניה: בחירת סחורה ← בחירת כמות (טונות שלמות) ← תשלום מזומן מיידי: `cost = qty * price[current_port][good]`.
2. מגבלת קניה יחידה: `cost ≤ cash`. **אין** מגבלת קיבולת — מותר לקנות מעבר לקיבולת הספינה.
3. מכירה: בחירת סחורה ← בחירת כמות ≤ הכמות במטען ← זיכוי מזומן מיידי: `revenue = qty * price[current_port][good]`.
4. אין קניה/מכירה בכסף בנקאי — מזומן בלבד (משיכה מהבנק נדרשת קודם; ראו `banking.md`).
5. כמויות בטונות שלמות, מינימום 1. אין כמויות שבורות.
6. הפעולות זמינות ללא הגבלת מספר פעמים ביום ואינן מקדמות את השעון.
7. ערך הספינה (משמש באירועים) = שווי הסחורות במחירי הנמל הרלוונטי + מזומן בלבד, ללא כסף בבנק (`תוכנית.txt`).
8. עסקאות סוחר נודד (אירוע בוקר) הן מערכת נפרדת — ראו `morning-events.md` §12.

## 4. Formulas

```text
buy(good, qty):   require qty ≥ 1 AND qty*price ≤ cash
                  cash -= qty*price ; cargo[good] += qty

sell(good, qty):  require 1 ≤ qty ≤ cargo[good]
                  cash += qty*price ; cargo[good] -= qty

cargo_total      = Σ cargo[good]
cargo_value(port)= Σ cargo[good] * price[port][good]
ship_value(port) = cargo_value(port) + cash          # ללא בנק
max_buy(good)    = floor(cash / price[good])
```

## 5. Edge Cases

- קניה עם מזומן 0 או מחיר > מזומן — נחסמת עם משוב ברור (לא שגיאה שקטה).
- מכירת סחורה שאין ממנה כלום — האפשרות מנוטרלת.
- העמסת יתר: מותרת בקניה; אזהרה תופיע רק לפני הפלגה (ראו `sailing-engine.md`). ה־UI המודרני יציג חיווי חריגה כבר בקניה (שיפור תצוגה, לא שינוי לוגיקה).
- קניה שמרוקנת את המזומן עד 0 — חוקית לחלוטין.
- אין מכירה בחסר (short) ואין קניה עתידית — רק ספוט.
- ⚠️ תקרת כמות בעסקה אחת במקור לא ידועה (כנראה מוגבלת רק בכסף/מלאי). הנחת עבודה: ללא תקרה נוספת.
