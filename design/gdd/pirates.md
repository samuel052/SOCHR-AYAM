# GDD — שודדי ים (pirates)

> שכבה: Core | סטטוס: Draft | מקור אמת: `סיכום שודדי ים.txt` (פיענוח); מילויי פערים: `התפלגות סיכויים.txt` ⚠️
> מוסכמה: `rand(n)` = שלם אחיד `0..n-1`; חלוקה שלמה = קיטום.

## 1. Overview

אירוע ההפלגה הדרמטי ביותר (30% מכל הפלגה שהגיעה לטבלה הרגילה): ספינת שודדים עוצרת את הסוחר, והוא בוחר — קרב, בריחה או פשרה. כוח הקרב נקבע ע"י ספינות המשמר שנשכרו לפני ההפלגה; הבריחה תלויה בעומס ובנזק; והפשרה היא מו"מ כלכלי מול דרישה נסתרת.

## 2. Player Fantasy

רגע השיא של המשחק: דגל שחור באופק וכל ההון על הסיפון. ההחלטה — להילחם, לברוח או לשלם — נשענת על הכנות שנעשו מראש (משמר, עומס, מצב הספינה), כך שגם הפחד וגם הביטחון מורגשים כמשהו שהשחקן בנה בעצמו.

## 3. Detailed Rules

### 3.1 כניסה לאירוע

- מתרחש כאשר `rand(20)+1 ∈ 1..6` בטבלת האירועים הרגילים (ראו `sailing-engine.md` §3.10).
- לשחקן שלוש אפשרויות: **קרב**, **בריחה**, **פשרה**.

### 3.2 קרב

כוח קרב = מספר ספינות המשמר שנרכשו להפלגה זו.

```text
roll1 = rand(4)                 # 0..3
if power > roll1:        ניצחון
elif power > 0:
    roll2 = rand(6)             # 0..5
    if roll2 == 1:       ניצחון
    else:                הפסד
else:                    הפסד   # power == 0 ⇒ הפסד ודאי
```

הסתברויות נגזרות: כוח 0 ⇒ 0% | 1 ⇒ 37.5% | 2 ⇒ 58.3% | 3 ⇒ 79.2% | 4+ ⇒ 100%.
⚠️ סתירה מול טבלת האפיון (1%/51%/76%/88%/94%/97%) — מקור האמת: הפיענוח. הפער ייבדק ב־DOSBox (סדרת קרבות עם 0 ו־4 משמרות מכריעה מיד: לפי הפיענוח 0 משמר = הפסד תמיד, 4 = ניצחון תמיד).

### 3.3 ניצחון

1. שלל: `rand(3) == 1` (‏1/3) ⇒ **לכידת ספינת השודדים**: `capacity += 50`.
   אחרת (2/3) ⇒ **מטמון**: `loot = (rand(15)+5) * 100` ⇒ ‏500–1,900 ש"ח, כפולות 100.
   ⚠️ סתירה מול האפיון (50/50; לכידה +25..קיבולת; מטמון 100..שליש שווי) — מקור האמת: הפיענוח.
2. נזק: `rand(4) == 0` (‏25%) ⇒ `dmg = (rand(15)+5) * 10` ⇒ ‏50–190 ש"ח, כפולות 10.
   ⚠️ סתירה מול האפיון (סיכוי נזק תלוי משמר 90%..1%; גובה 1..1/5 מהכסף הכולל) — מקור האמת: הפיענוח.

### 3.4 הפסד

⚠️ **פער**: הפיענוח לא כיסה את ענף ההפסד. מילוי (אפיון):
1. גניבה: `stolen = rand(trunc(cash/5)) + 1` — ‏1 עד 1/5 מהמזומן שעל הספינה (הבנק מוגן).
2. נזק: `dmg = rand(trunc(total_money/2) - 100 + 1) + 100` — ‏100 עד מחצית הכסף הכולל; `total_money` כולל בנק לפי האפיון ⚠️.
לאימות DOSBox (עדיפות גבוהה — ענף שכיח במשחק אמיתי).

### 3.5 בריחה

```text
# שלב 0 — פסילה מוקדמת:
if cargo_total > 0.81 * capacity:  הבריחה נכשלת מראש

# שלב 1 — בדיקת עומס:
escape_n = trunc(capacity/30) - trunc(cargo_total/30) + 1
if escape_n < 1: escape_n = 1
if rand(escape_n) == 0:  כישלון      # ככל שהספינה ריקה יותר, escape_n גדול והכישלון נדיר

# שלב 2 — בדיקת נזק:
dmg_n = trunc(damage/30) + 1
if rand(dmg_n) == 0:  הצלחה          # ללא נזק: dmg_n=1 ⇒ rand(1)=0 ⇒ הצלחה מובטחת
else:                 כישלון
```

- ספינה ריקה ותקינה בורחת כמעט תמיד; עמוסה או פגועה — בקושי.
- הודעות כישלון לפי מצב: יש מטען ⇒ "ספינתך כבדה מדי, ולא הצליחה לברוח"; אין מטען אך יש נזק ⇒ "לא הצלחת לברוח עקב הנזק שבספינתך"; אין מטען ואין נזק ⇒ "ספינת הפיראטים המהירה הצליחה להשיג את ספינתך".
- **כישלון בריחה ⇒ קרב** (לפי §3.2, עם אותו כוח).

### 3.6 פשרה

1. השחקן מציע שילוב של כסף/נחושת/זיתים/חיטה. ולידציה: ערכים שליליים מתוקנים ל־0; הצעה מעל המצוי ⇒ נפסלת.
2. שווי ההצעה מחושב ב**ערכים קבועים** (לא מחירי שוק!): נחושת 3,000, זיתים 500, חיטה 50 לטון.
   `offer_value = cash_offered + 3000*copper + 500*olives + 50*wheat`
3. דרישת השודדים: `demand = trunc( (fixed_cargo_value + cash) / (rand(6)+4) )` — המחלק 4..9; ‏`fixed_cargo_value` באותם ערכים קבועים; `cash` = המזומן שעל הספינה.
4. קבלה רק אם `offer_value > demand` (חד). התקבלה ⇒ הרכיבים נגבים וההפלגה נמשכת. נדחתה ⇒ לא נגבה דבר ⇒ **קרב**.
5. ⚠️ השערה חזקה מהפיענוח: רכיב כסף מותר בהצעה רק אם `cash > fixed_cargo_value / 10`; אחרת רכיב הכסף ננעל על 0. לאימות DOSBox.

### 3.7 ספינות משמר

- נרכשות במעטפת ההפלגה (ראו `sailing-engine.md` §3.1); תמחור ⚠️ לפי האפיון: 2% מערך הספינה, מינימום 75, ‏+50% סערה, ‏+25% לילה.
- משמשות אך ורק כ"כוח קרב" באירוע זה. תוקפן: ההפלגה הנוכחית ⚠️ (הנחת עבודה).

## 5. Edge Cases

- קרב עם 0 משמרות = הפסד ודאי — השחקן חייב לדעת זאת מראש? במקור לא הוצג; ה־UI המודרני לא יציג אחוזים (נאמנות), אך מסך העזרה ירמוז כמו העזרה המקורית ("ככל שיש יותר משמר — הסיכוי גדול").
- בריחה עם `cargo == 0.81*capacity` בדיוק: התנאי הוא >81% ⇒ לא נפסל.
- פשרה של 0 (הצעה ריקה): ‏`offer_value=0` לעולם לא > demand ‏(demand≥0) ⇒ דחייה ⇒ קרב. demand=0 ייתכן רק כשאין כסף ואין מטען — גם אז 0>0 שקר ⇒ קרב.
- פשרה בהצעת כל הרכוש עדיין יכולה להידחות (מחלק 4 ⇒ דרישה 25% מההון; הצעה חוקית תמיד יכולה לעבור — אבל שחקן חסר־כל לא יכול להציע דבר).
- לכידת ספינת שודדים בהפלגה עמוסה: הקיבולת גדלה מיד — עשויה לבטל עומס יתר קיים.
- הפסד לפיראטים כשאין מזומן כלל: הגניבה ⚠️ 0/מינימלית; הנזק עדיין נגרם. גבולות מדויקים ייקבעו באימות.
- כישלון בריחה ואז ניצחון בקרב — אפשרי ותקין (הבריחה רק דוחה לקרב).
