# עיצוב המשחק

זהו אזור העבודה המחייב לשלב העיצוב של ״סוחר הים״.

## חומר קיים

`reference-materials/` מכיל את האפיון שהכין המשתמש, הדמיות חזותיות, תוכנית מוקדמת וצילומי מסך של המשחק המקורי. יש לקרוא את החומר לפני הצעת כיוון עיצובי.

## תוצרים חדשים

- `gdd/` — חזון המשחק, עקרונות, לולאת משחק והגדרת מערכות.
- `ux/` — זרימות, מפרטי מסכים, ניווט, משוב ונגישות.
- `registry/` — רישום ישויות ותלויות של תשתית הסטודיו.

חומרי הייחוס אינם משנים את חוקי המנוע. אם דרישת עיצוב מתנגשת במכניקה המאומתת, יש להציג את ההתנגשות למשתמש ולהפריד בין מצב ״נאמן למקור״ לבין שינוי משחקיות אופציונלי.

## משימת העיצוב הבאה

לרכז את כל חומרי `reference-materials/` לטיוטת `gdd/game-concept.md` ולמפת מסכים תחת `ux/`, להציג למשתמש את ההחלטות והפערים, ולקבל אישור לפני שינוי רחב בממשק.
