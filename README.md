# סוחר הים — רימיקס מודרני נאמן למקור

זהו המאגר הראשי והיחיד של פרויקט **סוחר הים**. מטרת הפרויקט היא לבנות משחק דפדפן חדש ומעוצב, תוך שמירה מדויקת על חוקי מנוע משחק ה־DOS המקורי.

## מצב הפרויקט

- פענוח `K.COM` הושלם וכיסה את כל 52,098 הבתים.
- מנוע המשחק מומש ב־JavaScript ונבדק מול המפרט המאומת.
- 56 בדיקות רגרסיה עוברות.
- השלב הבא הוא גיבוש העיצוב וחוויית המשתמש מתוך חומרי העיצוב הקיימים.

המצב המדויק והמשימה הבאה מפורטים ב־[`PROJECT-STATUS.md`](PROJECT-STATUS.md).

## התחלה מהירה

דרישות: Node.js מודרני. אין צורך בהתקנת חבילות.

```powershell
npm test
npm run verify
npm run serve
```

לאחר `npm run serve` המשחק זמין ב־`http://127.0.0.1:8631`. ב־Windows אפשר גם להפעיל את `play.bat`.

## מבנה המאגר

| נתיב | תפקיד |
|---|---|
| `src/` | הקוד הפעיל היחיד: מנוע, ממשק ובדיקות |
| `design/` | תוכנית העיצוב וחומרי הייחוס; מכאן מתחיל השלב הבא |
| `docs/reverse-engineering/` | הפענוח המאומת ומפת הבתים של המשחק המקורי |
| `reference/original-game/` | קובצי משחק ה־DOS המקוריים; חומר קריאה בלבד |
| `tools/` | כלי אימות והפעלה מקומית |
| `archive/legacy-analysis/` | פענוחים ישנים שאינם מקור סמכותי |
| `.claude/` ושאר מסמכי התשתית | סוכנים ומיומנויות אופציונליים לניהול הפיתוח |

## היררכיית אמת

במקרה של סתירה:

1. `reference/original-game/K.com` והבדיקות האוטומטיות.
2. `docs/reverse-engineering/10 - מפרט מנוע מאומת סופית.md`.
3. קוד המנוע תחת `src/core/`.
4. יתר מסמכי הפענוח.

הקבצים תחת `archive/` לעולם אינם משמשים להכרעה.
